# Immutable UI build fixture

The standalone `prepare-ui.mjs` and `build.mjs`, their source-tree copies,
UI source/configuration/readme/consumer test and root notices are byte-exact
Git blobs from Waitron commit `9b6e19be507150daca3b2b42660e77f0b8cb7f8c`.
The programs originate at `scripts/release/prepare-ui.mjs` and
`packages/ui-core/scripts/build.mjs`. Their SHA-512 values are tested.

The root manifest, reduced UI development-dependency list, workspace examples,
lock, ignore file and check definition are synthetic offline fixture data.
Their integrity strings identify synthetic bytes; nothing fetches those bytes.
This is a reduced Git repository for inventory tests, never a qualifying source
build, frozen installation, package-consumer result or source CI receipt.

The copied files retain Waitron's Elastic License 2.0 and additional grants,
in `source/LICENSE` and `source/LICENSE-GRANTS.md`. Inventory tests do not
execute source programs. Tool probes use owned deterministic tools and a
copied trusted Git executable. Tests need no external checkout or registry.
