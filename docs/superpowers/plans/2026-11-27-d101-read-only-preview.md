# D101 read-only sales preview

> CLOUD-EXIT. A venue leaving Cloud can download its data and read it for 90 days

In disposable Test Cloud, a venue owner selects a verified snapshot in Backups, confirms their sign-in and opens **Preview recent sales** after recorded service end and before the existing 90-day deadline. Show the issue time and formatted total for up to 25 sales, newest first. Read the stored totals as cents, as Waitron’s receipt reader does. Show the capture time because later sales may be missing. Explain empty, oversized and unsupported snapshots in English and Spanish. Cap the encrypted archive and extracted database at 16 MiB each.

The watcher’s 27 November 19:40 direction puts read-only use next. Full return also needs a consistent database with module and vault state, the latest backup and matching key, a format manifest, checksums, restore instructions and proof of offline recovery. This slice reads only the local snapshot. [D101 §6](../specs/2026-10-22-cloud-data-protection-design.md#6-make-cancellation-return-and-deletion-one-recorded-instruction)
