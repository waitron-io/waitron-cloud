# One-click Cloud pairing

You can open Cloud from the Waitron box and see the venue to approve, without typing its pairing code or clicking Check code. You still sign in, choose the business if you have more than one, and approve it. The owner’s 19 November direction also puts registration or sign-in for basic services in setup and reserves box registration for second-level services after an opt-in trial. That setup change needs its own Waitron assignment. This slice changes how the existing registration starts.

## Cloud first

- In `apps/portal/src/links.ts`, accept an optional eight-digit `code` alongside the existing `request` in the `/connect` URL fragment, the part after `#`. Accept one of each. Reject codes in query strings, on another page, without a valid request, or with duplicates. Keep request-only links and scrub the address before rendering or making requests, including on refusal.
- In `apps/portal/src/app.ts` and `apps/portal/src/pairing-controller.ts`, carry the code in tab memory through first sign-in. When the authenticated pairing page has loaded at least one eligible business, call its existing inspect action once. Use the existing manual input and retry on refusal. Clear the code on sign-out, account or request replacement and leaving the journey. A reload or signup in another tab uses Open Cloud again, with the existing restart if the request expired. Keep the current approval screen and its explicit action.
- Cloud approval checks that the signed-in account may register the venue under the selected business and has fresh account verification (`packages/registration/src/pairing.ts:89–119`). Inspecting imports the code without approving the venue. Reuse the existing endpoints and signed exchange.
- Test first in `apps/portal/test/links.test.ts` and `apps/portal/test/pairing-browser.test.ts`. The parser owns link format and scrubbing. The PostgreSQL-backed browser proves sign-in returns to the venue with one inspect request and no stored approval before the click, and that manual entry and account clearing still work. Run the existing pairing account-fencing test for stale replies. Inspect English and Spanish, both themes, at 390 and 1280 wide. Estimate 70–120 implementation lines and 90–140 test lines.
