- For Kind, start the original two-peer WireGuard metrics check alongside bridge repair under the same 180-second deadline. Log each result and failure reason to stderr as it settles, labelled by path. Keep both full drive reads before bridge repair and require zero incomplete objects within three attempts. Print the live receipts before asserting that all three WireGuard checks passed. This estimate uses the earlier pair and is not a guarantee. Keep both limits.
