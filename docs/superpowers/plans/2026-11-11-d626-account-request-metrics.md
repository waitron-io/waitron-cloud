## Smallest build

Reuse `server.ts`’s Node listener/Hono adapter, admission and portal selection; the collector’s polling/freshness; `operations-health.mjs`’s transport; fixed-label formatting conventions in `packages/operations/src/metrics.ts`. This is source assessment, not execution evidence.

- Add `packages/account-http/src/request-metrics.ts`: finite accumulator, bounded JSON snapshot validation and Prometheus formatting, imported directly by the collector. Groups: `health`, `account`, `installations`, `relay`, `portal`, `other`, `parser`; use decoded segment boundaries and existing portal precedence. No raw URL, query, ID, token, Host, email or exception label.
- Outcomes: `success` = 2xx/3xx; `refused` = 4xx except 408, plus explicitly marked admission/shutdown 503; `server_error` = remaining 5xx; `timed_out` = 408 or `ERR_HTTP_REQUEST_TIMEOUT`. Existing wire answers stay unchanged.
- Export `waitron_cloud_account_requests_total` and `waitron_cloud_account_request_duration_seconds_{bucket,sum,count}` by group/outcome; cumulative bounds 0.05, 0.1, 0.5, 1, 5 seconds and `+Inf`. These are measurement bands, not targets. Preallocate finite series; reset on process restart.
- Time from Node request admission until response `finish` using a monotonic clock, including early refusals and adapter failures. `clientError` settles an associated unfinished request once, or a `parser` observation from connection acceptance when no request exists. Share settlement guards; keep-alive requests remain distinct and closed sockets are not retained. Parser-only connection timing has a different start; exclude disconnects without a completed response or observed timeout. Never treat idle keep-alive as application work.
- An optional separate read listener owned by `startAccountServer` serves exact `GET /metrics` as bounded JSON with `no-store`, other requests 404, and excludes its own scrapes. `server-cli.ts`: strict `CLOUD_LOCAL_REQUEST_METRICS=0|1`, default off, refused in production. Local account runtime alone enables container `0.0.0.0:9092`; no host publication, public account route, ingress or Compose change. Close both listeners and clean up partial startup.
- Extend `operations-health.mjs`: fixed `http://account:9092/metrics`, two-second deadline including body, 32 KiB bound, status/JSON/schema checks, no redirects. `operations-sample.mjs` adds `accountRequests`; collector validates/formats it within its existing poll. Missing/failed counters fail collection; existing failed/stale suppression covers both exports. General operations CLI/readiness unchanged.
