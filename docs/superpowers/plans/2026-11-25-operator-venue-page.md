# Operator venue page

The owner on #1408 asked “why would i need to type a venue ID? i should be able to go to their profile and disable it by clicking a button”. Lane J’s watcher assigned the first console slice at 10:28 on 25 November. A test operator finds a synthetic venue by name and stops or allows address suggestions from its page. Waitron merged its manual sender in #4098 and #4104. Cloud #1371 covered exact Sent reports in the synthetic owner browser test. [D609](../specs/2026-11-07-cloud-operator-console-support-design.md) · [Backlog](../../backlog.md#free-services-for-open-source-waitron)

**Portal.** Link **Find a venue** from the authorized repair view when the server advertises demo access. Use one `/operator/venues` page for search and detail. Capture a venue link’s `#venue=<uuid>` in the current history entry and return there after sign-in or refresh. Reuse the displayed search row when opening a result. On reload or after a lost write reply, read the saved state. Show the name, stop state and **Stop address suggestions** or **Allow address suggestions**. Allowing suggestions leaves provider settings and limits in force. Update `apps/portal/src/{api,app,links,screens,locale,cloud-actions-screen}.ts`, the venue screen and controller, and `packages/account-http/src/portal.ts`. Use existing controls and add the paths to the client’s CSRF, reply validation and retry handling.

**Server.** Only the LAN account worker passes `operatorVenues` from `actionDemoEnabled` through `startAccountServer` to `createAccountApp`. Routes return 404 when disabled and construction refuses production with the option enabled. Use POST `/api/account/operator/venues/read` for name or ID and POST `/api/account/operator/venues/address-lookup` to set state. Reuse session, configured operator, exact origin, CSRF and bounded JSON with separate limits from repairs. Read only test venues in the configured business country. Search named venues by literal case-insensitive substring, 3–80 characters, with accents matched. Return `{id,name,stopped}` or ask for more letters when over ten match. Show IDs only for duplicate names. Permit direct reads of in-scope unnamed venues. Require fresh proof before finding the write target and again after waits. Take the venue row lock that lookup admission uses, then insert or delete its stop row. Admitted calls and usage stay intact.
