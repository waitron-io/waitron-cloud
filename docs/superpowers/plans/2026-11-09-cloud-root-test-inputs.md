**Implementation mechanism.** Add `scripts/ci-root-selection.mjs` with a small, explicit omission table following the existing immutable receipt-audit pattern. A missing, changed or nonregular audited input retains its test; unknown/shared inputs retain full root work. No JavaScript parser or generated audit registry.

`ci-plan.mjs` adds an optional sorted `rootFiles` list only for eligible, verified PR ranges. Missing `rootFiles` means legacy full root execution. Extend `ci-root-inputs.mjs` to reconstruct and compare that list from the trusted event range. Its inventory must include **all four** explicit files.

Keep the eight existing job names, partitions, concurrency and time limits for this slice. The workflow invokes the selector’s guarded CLI to run the explicit nonempty list with the existing Node flags and shard number; an intentionally empty partition is reported explicitly. An empty overall selection skips root jobs. This cuts test execution while retaining eight-job setup overhead; changing shard allocation is a separate optimisation.
