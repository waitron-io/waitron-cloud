# D621 relay startup from a private checkout

The Stockholm launcher checked out Cloud under `umask 077`. A free Docker reproduction gave `/app/deploy` mode 0700 and the relay script mode 0600, both owned by root. The relay executes as user 1000 and exited with `MODULE_NOT_FOUND`. A Git archive of the same source gave those paths modes 0755 and 0644. The relay opened its listeners. The Stockholm run kept no relay process log, so the free result identifies a defect in its recorded setup and the paid result remains unconfirmed.
