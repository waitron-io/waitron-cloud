# D621 relay startup from a private checkout

The Stockholm launcher checked out Cloud under `umask 077`. In the free Docker reproduction, the resulting image gave `/app/deploy` mode 0700 and the relay script mode 0600, both owned by root. The relay runs as user 1000 and exited with `MODULE_NOT_FOUND`. A Git archive from the same checkout gave the corresponding paths modes 0755 and 0644. The same relay opened its listeners. The paid run kept no relay process log, so the free result reproduces the startup failure from its recorded setup.
