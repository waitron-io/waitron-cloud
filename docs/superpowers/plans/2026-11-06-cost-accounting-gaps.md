# Cost accounting gaps: design and implementation plan

> **For agentic workers:** Use `superpowers:executing-plans` inline, task by task. Inline execution is authorised. Present the required changed-check report before code lands. This document authorises no provider action or new cost sample.

**Goal:** Finish a functionally sound rehearsal with explicit unknown cost, while preventing that run from exporting measurements or replacing published cost evidence.

**Architecture:** Separate functional health, accounting coverage and publication eligibility. Record accounting gaps where they arise; carry them through worker admission and cleanup without turning them into functional exceptions. Keep historical receipt readers and clean measured output unchanged.

**Stack / spec:** Node.js ESM, `node:test`, loopback HTTP, SQLite, official Litestream **0.5.17**; this document contains both spec and plan. The owner's latest 2026-11-06 ~10:25 instruction supersedes older retry and LIST-only proposals: **what rehearsal checks can fail it; what it counts cannot**.

## Decisions and strict boundaries

- In **every mode**, a cut-off request of any operation, disagreement between meters, incomplete total or unknown billing produces named accounting gaps and unknown affected figures. No mode flag, retry/LIST whitelist or process-exit-zero exception controls this policy.
- Keep failures for missing sales, missing required uploads, invalid stop acknowledgement, failed/late stop, restore failure, SQLite or fiscal corruption, unsafe storage/control operations, isolation, ownership and cleanup. Keep request/resource caps and all deadlines, including the **three-request after-stop guard** and **one absolute two-second stop budget**. No cap/retry changes; all official 0.5.17 pins/digests remain.
- Malformed harness inputs still refuse: private/extra fields, getters/proxies, invalid enums, impossible row arithmetic, unsafe individual numbers, bad target/ownership, invalid mutation controls or clocks. Well-formed runtime observations that are absent or disagree are accounting gaps. An aggregate arithmetic overflow makes that figure unknown; it does not turn valid individual events into malformed inputs.
- Count bounded admitted work independently of successful cost reconciliation. Late operation/retry shape and missing witnesses must not become accounting-based forwarding refusals. Preserve request identity/shape safety and the existing resource bounds; do not silently create a new retry policy.
- Split lifetime **accounting** uncertainty from failed storage **operations** and unsafe inventory/control data. An ambiguous retained-size history may lose its measured value; a failed delete, uncollectable client, ownership loss or incomplete cleanup still fails. Never catch arbitrary errors and return a successful rehearsal.
- Do not mark a partial observation as a full total. Keep actual first/second-hop observations and discrepancies as diagnostics. Affected complete totals and billing quantities are `null`, with unknown status and named gaps. Retain a known row only when independent witnesses still support that row, including its phase, class, retry/outcome and coverage; no blanket promotion from equal grand totals.
- A run with gaps can finish its functional rehearsal but **cannot enter new measurement export/publication**, even if some rows remain known. It cannot overwrite a published figure. Existing static receipts can still be read as historical component evidence, with their original unknowns; this does not approve a new gapped run. `costMeasured:false` alone is not an eligibility check.

## Result contract

Add `scripts/cloud-cost/accounting-policy.mjs` with `assessAccounting({producer, sources})` returning the closed record `{status, gaps, publicationEligible}`. Sources retain original validated domain records, including billing and gap fields, rather than caller-computed summary flags. Required scopes are fixed by producer: local-stream and archive require `requests`, `restore`, `administration`, `storage`; service additionally requires `mail`, `fiscal`; remote requires `remote`. Reject duplicate/unknown scopes and malformed records. Missing coverage, unknown status/billing, disagreement or any gap yields unknown status and false eligibility. An empty source list cannot qualify. Validate closed descriptors and bounded arrays before access.

Use fixed codes: retain applicable existing `litestream:*`, `after-stop:*`, `accounting:unreconciled`, `request-billing:unknown`; add `accounting:request-cutoff`, `accounting:meter-disagreement`, `accounting:incomplete-total`, `accounting:incomplete-history`, `accounting:overflow`. Close the vocabulary in one place; diagnostics carry only admitted operation/phase codes and bounded counts, never raw error text, paths, keys, headers or SDK logs.

Add `markGap(code)` to the meter/audit accounting side; reserve fatal invalidation for malformed/unsafe input and real lifecycle failure. Pending work during observation is not automatically missing; at bounded finalisation, incomplete work becomes a gap after owned work is collected. Expiring the execution/collection deadline remains fatal.

For a completed gapped run, return `{functional:'passed', costMeasured:false, accounting: assessment, receipt:null, evidence}` through the closed worker/host boundary; `evidence` contains only validated anonymous observations and independently supported rows. Do not use this envelope when functional checks or cleanup fail. Preserve the existing clean result/receipt shape and values; normalise both variants at admission, without reinterpreting existing meter `status` as overall cost status.

Keep `validateReceipt(receipt)` as historical readback. Change new export to `exportAggregate(receipt, {producer, sources})`: recompute eligibility from those original records and cross-check the receipt's accounting/measurement projections against the same records. Never accept a caller-supplied eligible summary. Update every direct caller. New local/archive/service/remote candidate producers assess evidence before dropping billing/gap fields; historical readers remain separate. `run-local.mjs` returns the gapped result without invoking its receipt builder. Public sample admission rejects diagnostic envelopes rather than repairing or stripping them.
