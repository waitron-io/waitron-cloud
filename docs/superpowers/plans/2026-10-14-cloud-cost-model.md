# Cloud cost model implementation plan

> Execute inline, task by task, using `superpowers:executing-plans`. No subagents. The owner has authorised unattended execution; the first branch contains this plan, its design and a backlog link. Implement only after that branch is landed; private source inventory alone is not cost measurement.

**Goal:** Explain the AWS platform floor and per-venue cost with reproducible evidence and an offline calculator.
**Architecture:** Cloud owns a small measurement/accounting harness and a pure calculation module. Private replay produces allowlisted aggregates; public list prices and those aggregates feed the document/HTML. One independently generated synthetic storage run checks a bounded subset against AWS billing.
**Stack:** Node 26 native `node:test`, existing PostgreSQL 18/SeaweedFS/Litestream/Waitron fixtures, existing Playwright. No production service changes or Waitron edits.
**Spec:** `docs/superpowers/specs/2026-10-14-cloud-cost-model-design.md`; read it with this plan.
