## Contract proposed for slice 3

- A central guest listener, beside the account service with its existing database pool, owns `GUEST_ORIGIN/m/<venueUuid>?lang=en|es|ca|gl`. Local origin: `https://menus.example.test`; operator-supplied local-CA certificate/key, no client certificate. Production domain/certificate deployment remains separate. Account host/query restrictions remain intact. Guest TLS and stored copies survive expired gateway authority.
- Central lookup resolves the venue's current public hostname/cell; existing gateway TLS and WireGuard reach its box. Both HTTPS hops verify hostname/chain, using explicit local CAs in rehearsal. Gateway admits only GET/HEAD `/public/menu` with the language query before Waitron staff authentication; retain every staff restriction. Reject other parameters/paths, bodies, upgrades and redirects; never relay guest credentials/cookies. Buffer at most 2 MiB HTML, five-second upstream limit; replace response headers with no-store and CSP denying scripts, external assets, forms, framing and base changes, permitting inline styles.
- Box POSTs installation API `/api/installations/guest-menu-{publish,status,withdraw}`, matching signing actions. Reuse installation proof, lease/origin binding, parent-first locks and current serving-installation checks. Waitron must release these actions: its `packages/contract/src/signing/installation-proof.ts` has a closed action list; Cloud retains its verifier. No browser Origin accepted.
- Publish envelope `{payload,signature,body}` reuses registration's `box-error-reports.ts` well-formed raw-string/digest check: signed body `{version:1,expectedRevision,bodySha256,bodyBytes}`; `body` is UTF-8 JSON `{defaultLanguage,pages}`, pages mapping supported languages to self-contained published HTML. Hash exact bytes, no canonicalisation; maximum 2 MiB body, outer JSON maximum 12 MiB + 16 KiB to cover escaping. Status/withdraw signed body `{version:1}`. Every success: 200 `{version:1,url,revision,state,publication}`; state `off|current|blocked`; publication null or `{bodySha256,defaultLanguage,receivedAt}`. Current means durably stored. Same-current-publish retry returns unchanged confirmation; otherwise stale revision refuses 409/conflict. Errors `{error:code}`: 400/invalid_input, 403/forbidden, 413/too_large, 423/blocked, 503/unavailable.
- One venue row holds revision/state/source/pages; absent status is revision 0/off. Each state/content change atomically increments revision; identical retries do not. Same-current digest/default language confirms despite stale revision. Withdraw clears to off; blocked status remains readable. Each worker pass compares desired sharing/digest with status, repairing stale withdrawal or rereading after 409. Portal owner/CSRF POST `/api/account/guest-menu/{takedown,enable}` body `{venueId}`: idempotent takedown commits blocked state and removes bytes; enable returns to off. Blocked publishers cannot undo takedown. Takedown confirms after commit; subsequent requests return 404. Recheck before releasing buffered responses; bytes already in flight cannot be recalled. Guest reads never delete copies. Relay transport/502/503/504 or gateway 403/404/405/413/421/429 falls back to the dated copy. Gateway strips box markers and stamps `X-Waitron-Menu-Upstream: box` only on box replies; only marked 403/404/410 refuses without deleting the copy. Off/blocked returns 404; missing copy/storage uncertainty 503.
