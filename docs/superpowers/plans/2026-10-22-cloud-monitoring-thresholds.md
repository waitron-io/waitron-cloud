The approved inventory contains fixed targets and parent source scopes, never a hand-maintained list of future queue IDs. Task 8a discovers item targets within each current scope. Only a source has `scope`; only an item has `sourceId` and a bounded canonical `sourceItemKey`. Mail scopes explicitly name permitted test installations and whether administrative account mail is included; job scopes name permitted test installations; usage scopes name expected source keys. No scope widens existing data access or delivery authority. Mail and job states remain per item, never overwritten by another item's healthy result. Export runtime `signals` and `targetKinds` readonly lists with the corresponding literal unions.

`binding` is a SHA-256 digest of the current private identity tuple, including installation, configuration revision, relevant hostname/service and source generation/target when applicable. It is not a metric label or phone field. State `p1At` is first committed eligibility, never last evaluation time. The committing repository allocates an episode UUID on first detection. Pure reducers may return a newly detected state with null episode ID until persistence; unknown and P2-to-P1 retain the persisted ID. Suppression and a later distinct opening create a new episode. Persist recovery separately in episode history before clearing current state. The pure reducers do not allocate random IDs or read clocks.

Task 1 exports `initialState(key: SignalKey): SignalState`, `validateSample(value: unknown, now: Utc): Sample`, `evaluateSamples(previous: SignalState, input: {now: Utc; enabled: boolean; enabledAt: Utc; collection: CollectionEvidence; sample: Sample | null}): Evaluation`. Validation refuses noncanonical/invalid times and samples ahead of trusted database/observer time. Existing producer acceptance up to +60 seconds is preserved for legacy consumers, but such evidence remains unknown to C39 until time catches up. Do not clamp future times to now. Equality at age 300 seconds is stale.
