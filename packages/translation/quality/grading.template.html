Menu name grading

Each card is one of Santet's products, shown by its internal name as staff see it. Under each language are the customer-facing names the models wrote for it, every distinct answer once, in a shuffled order and with the model hidden.

Names marked New come from the latest round; everything else you have already seen, and anything you left unmarked counts as good.

Leave a good name alone. Mark one Needs work if it is understandable but not how a menu should say it, or Wrong if it misleads a customer. Click a mark again to clear it. Mark a card done when you have read it all.

Some cards now list suggested spelling corrections: fixes the model proposes to the internal name, or to a name someone already entered (which it leaves unchanged). Mark a correction Wrong if it is not a real fix.
